Material 3 palette generator

Input one seed color, get the exact ColorScheme Flutter's ColorScheme.fromSeed() would produce from it — computed with Google's real Material Color Utilities library (HCT color space), not an approximation. Cairn's own theme (lib/main.dart) uses the Expressive variant, selected by default below.
